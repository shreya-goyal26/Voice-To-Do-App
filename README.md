# 🎙️ Voice To-Do App

A simple voice-controlled To-Do List application built using **HTML, CSS, and JavaScript**. This project uses the browser's **Web Speech API** to recognize voice commands, allowing users to add, delete, and mark tasks as completed without typing.

## 🚀 Features

* 🎤 Add tasks using voice commands
* 🗑️ Delete tasks using voice commands
* ✅ Mark tasks as completed
* 📋 Dynamic task list updates
* 🔊 Speech recognition with Web Speech API
* 💻 Clean and beginner-friendly user interface
* ⚡ Built with pure JavaScript (No Frameworks)

## 🎮 Supported Voice Commands

### Add a New Task

```text
New Task buy milk
```

### Delete a Task

```text
Delete Task 2
```

### Mark a Task as Completed

```text
Mark Task 1
```

## ⚙️ How It Works

1. Open the application in your browser.
2. Click the **🎙️ Start Listening** button.
3. Speak one of the supported voice commands.
4. The application converts speech into text.
5. The corresponding action is performed automatically.
6. The task list updates instantly on the screen.
